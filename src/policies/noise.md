# Noise policy

Scope: spam, marketing, wrong-property or wrong-agency messages, duplicates of an already-open case, automated notifications with no action.

## Rules
- Close with no action and say why. Do not reply to marketing. Do not create tickets for duplicates: update the existing ticket with a note instead.
- Wrong-property messages that still describe a hazard are not noise: route on the content, flag the property mismatch.
- A duplicate from a different reporter about the same issue is a signal (building-level or worsening), not noise: update the ticket and raise urgency if warranted.

## Escalate when
- You are not sure it is noise. Uncertain noise is handled by the generalist as a real case.
