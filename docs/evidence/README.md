# Evidence of execution

All files here are generated by the system's own scripts from real runs on the Anthropic API on 10 Oct 2026; nothing is hand-edited.

- `sample-set-eval.md`: deterministic checks on our sixteen synthetic sample cases with an injected booking failure (`pnpm eval`).
- `public-cases-judge-baseline.md`: fifteen of the organisers' public cases, cut at a decision point, graded by the judge simulator against the hidden endings, morning baseline (`pnpm judge`).
- `public-cases-judge-merged.md`: the same fifteen after the state layer and the agency policy were merged.
- `capacity-model.md`: per-case timing and throughput computed from the traces of real runs (`pnpm capacity`).

## example-case-008/
One complete output folder from the fifty-case run (public case 008, cut at its decision point): `ANSWER.md`, `REASONING.md` and `trace.jsonl` exactly as the system wrote them. Used by the README's "How to read an answer" section. Nothing in it was edited.
